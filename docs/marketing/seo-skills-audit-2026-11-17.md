## 1. Summary for the founder

### Top 5 fixes shipped (in the PR)

1. **Two dead links now land somewhere.** `declutrmail.com/alternatives` and `declutrmail.com/vs` showed a "page not found" error. The outreach reply template for "alternative to Unroll.Me" questions links `/alternatives`. Both now forward permanently to the comparison hub at `/compare`.
2. **The AI-readable site guide (`llms.txt`) has one title again.** Its pricing section pasted in a second top-level title ("Free to start. Pay once to clear the rest.") and put each plan beside the site's own sections. Plans now sit inside the Pricing section. Its "Get started" link also pointed at the retired beta page, which forwards to How it works. It now points at sign-in.
3. **Search engines get breadcrumbs, an image and a publisher logo for every guide, answer and article.** 14 learning pages and 5 alternatives pages had no breadcrumb trail in their structured data. Articles had no image and no publisher logo, which article results expect. Journal posts are now marked as blog posts.
4. **Search-result titles and descriptions fit.** Four titles ran past about 60 characters and would be cut off. One description was 78 characters (InboxPurge comparison) and one was 85 (How undo works). Two ran past 160. The pricing page title was just "Pricing". The comparison hub and FAQ headings now name what the page is.
5. **The best-way-to-clean-Gmail answer is easier to find.** It had two links pointing to it. Two related how-to guides now link to it. Five cited sources that had moved (Meta, Paddle, Unroll.Me, MailMop) now link straight to their current addresses.

### Top 5 opportunities

1. **Get listed where "alternative to X" searches land.** The search results for "unroll.me alternative" were mostly AlternativeTo, GetApp and Capterra listings. DeclutrMail is on none of them yet. This is the cheapest way into those answers.
2. **Write pages for searches the site doesn't answer yet** (§5): sorting Gmail by sender, what happens when Gmail storage is full, deleting Gmail by date, applying a filter to existing mail, and why Gmail unsubscribe doesn't work. Each has a large cluster of Google autocomplete suggestions and no page on the site today.
3. **Answer "Is [tool] safe?" on the comparison pages.** Google suggests "is … safe" for Unroll.Me, Clean Email, SaneBox and Trimbox. The comparison pages already hold sourced facts to answer it, so this needs a new question on each page rather than a new page.
4. **Get mentioned by someone else.** No independent page mentioning DeclutrMail turned up in these searches. Answer engines learn about a product from reviews, roundups, forum threads and directories, not from the product's own site.
5. **Add phone steps to the existing guides.** Autocomplete is full of "on iPhone", "on Android" and "Gmail app" versions of the same tasks. The guides cover the web only.

### Decisions only you can make

1. **Make the GitHub repository private, or accept what it shows.** A search engine's AI answer about DeclutrMail quoted an internal issue: "legal entity and maker name were still pending". The repo, its issues and its pull requests are the only non-DeclutrMail pages that mention the product. Making the repo private also changes what GitHub Actions costs, so it is your call.
2. **Name the official profiles.** The site's structured data has an empty "same as" list (`ORGANIZATION_SAME_AS` in shared copy). Tell us which accounts are official (for example X, Product Hunt, G2) and it can be filled in.
3. **Check four AI assistants yourself, signed out or in a temporary chat.** I could not run these checks honestly: Perplexity needs an account, and ChatGPT was open only in your personal account, where its memory knows you built DeclutrMail. The prompt list is in §4.4.
4. **Paid plans in structured data.** Only the Free plan appears as an offer in the site's structured data. Adding Plus or the Backlog Pass there is a published price, which is a billing decision. Prices are on `/pricing` and `/pricing.md` either way.
5. **Two security headers** (not SEO-blocking): scripts are allowed to run inline, and the HTTPS-only header is not submitted to browsers' preload list. Listed in §3.1. No change made.

## 4. AI visibility detail

### 4.1 What answer engines can cite today

DeclutrMail's own pages, and only for its own name. The competitors that answer engines can cite have three things DeclutrMail lacks: "best X" and "X alternative" roundup pages on their own blogs, directory listings, and third-party reviews.

### 4.2 Products seen in results with no DeclutrMail page

Cleanfox, Gmailytics, PureBox, MailSweeper, InboxZapper, Inbox Zero, mailtrim and others (full list in research §A2). This is a list of names that appeared, not a ranking or a recommendation to write about each one. Any new comparison needs sources under CLAUDE.md §2.0 (Tier 1b).

### 4.3 Actions, by expected effect

1. **Directories first.** AlternativeTo (as an alternative to Unroll.Me, Clean Email and SaneBox), then G2 and Product Hunt. Use the vetted copy in `search-visibility-plan-2026-11.md` §4. _High._
2. **"Is [tool] safe?" questions on each `/vs` page**, answered only from that page's existing sources. _Medium._
3. **The five new pages in §5.** _Medium._
4. **Community answers** under the outreach playbook's rules: disclose that you built it, keep claims sourced, reply within 6 hours. _Medium, and slow._
5. **The GitHub decision** (§1). _Removes a wrong signal rather than adding a right one._

### 4.4 Prompt kit for the founder's own check

Run each prompt signed out, or in a temporary chat with memory off, in ChatGPT, Claude, Gemini and Perplexity. For each, record the date, whether DeclutrMail is named, its position, and whether the description is accurate.

1. What is the best tool to clean up Gmail by sender?
2. What are good alternatives to Unroll.Me for Gmail?
3. Is Clean Email safe to connect to Gmail?
4. How do I delete all emails from one sender in Gmail?
5. What is DeclutrMail?
6. DeclutrMail vs Clean Email — which should I use?

Accurate means it matches `llms.txt`: Gmail only; five sender decisions (Keep, Archive, Unsubscribe, Later, Delete); a preview before manual changes; 30-day undo for Archive, Later and Delete; "We never fetch or store full email contents."
