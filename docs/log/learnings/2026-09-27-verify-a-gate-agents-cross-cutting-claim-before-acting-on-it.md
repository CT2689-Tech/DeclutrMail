## 2026-09-27 — A gate agent's claim about cross-cutting behavior needs its own verification before you act on it

**Context:** Folding design-system-agent's re-gate findings into #808 (Quiet copy). One suggestion: skip the save-failure toast on a 402, because "the global MutationCache handler already opens the UpgradeModal for it."

**Finding:** The claim was plausible — `apps/web/src/lib/query-client.ts`'s `MutationCache.onError` does call `reportUpgradeGateHit` on every mutation failure — but wrong for this specific route. `upgradeGateHitFrom` (`apps/web/src/lib/entitlements/upgrade-gate.ts`) only recognizes `FREE_CAP_REACHED` / `INBOX_LIMIT_REACHED` / `ACTION_TIER_REQUIRED`; the quiet-hours PUT's `@RequiresCapability('quiet')` guard actually throws `PRO_FEATURE_REQUIRED`, which isn't in that list (confirmed against the guard's source and against `upgrade-gate.test.ts`'s own "unrecognized code returns null" case). Implementing the suggestion as given — trusting the reviewer's framing rather than reading the two files it depended on — would have made a downgrade-mid-session save fail with zero signal to the user, worse than the bug being fixed. The gap is real and reaches every `@RequiresCapability` route in the app (Screener, Autopilot, Followups, Briefs), not just Quiet — filed as `docs/log/founder-followups/2026-09-27-pro-feature-required-402-has-no-ui-route.md`.

**Rule (provisional):** A gate agent's finding about the LOCAL diff is usually safe to trust (it read the file). A claim about a SHARED, cross-cutting mechanism ("the global handler already covers this", "the convention elsewhere is X") is itself an unverified finding — read the mechanism's own source and its own tests before implementing the suggestion, not just the diff it's commenting on. This cuts both ways: the same discipline caught the reviewer's claim being wrong here, and separately confirmed (independently, at architecture-guardian) that the DST fix's claim ("lands on the configured end") held for 418,560 real cases before trusting it.

**Distillation trigger:** promote to CLAUDE.md §8 if a gate-suggested "skip this, X already handles it" turns out wrong a second time.
