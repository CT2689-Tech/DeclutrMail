## 2026-09-26 — Error copy named a cause its code never proved, and a signup followed it out
**PR:** #784 (https://github.com/CT2689-Tech/DeclutrMail/pull/784)
**Caught by:** founder's user-journey trace (2026-09-04 signup, mailbox `58c7eb82…`) + a `/ct-class` sweep
**What happened:** The scan gate mapped `TransientError` to "The scan kept losing its connection to Gmail…" (shipped in #471, the same PR that added a non-connection `TransientError` for "Gmail refused most messages"; on 2026-09-04 it read "…and ran out of attempts. Starting it again usually works."). `TransientError` is also a Google 5xx, an unrecognised 403, any other 4xx, a malformed response and a failed token refresh. The signup's dead-letters show three runs × 5 attempts of `403 insufficientPermissions`, a Gmail permission left unticked; they started it again twice and left. The row kept `TransientError` after a background call recorded `InvalidGrantError` the next night, so the gate went on offering the retry that could not work. The 2026-08-26 signup read "Waiting a minute before trying again usually clears it." after the worker had already backed off and been throttled, retried three times in 20 minutes (4–10 minutes apart) and never synced. The sweep found the same mechanism on the reconnect banners and email ("expired"/"renewing" for a withheld permission), four "Retry the scan in Settings" lines where Settings offers only Reconnect, Home's "review the connection", Sync now's "check the mailbox connection" (prod's recent failures were all Postgres lock timeouts), an any-409 bulk-unsubscribe sentence, "failed" for a not-accepted-but-emailable unsubscribe, billing's "couldn't reach the provider" for our own 429, and two error boundaries promising a retry or reload that nothing runs.
**Correct approach:** Before writing a sentence keyed on an error name or status, list every producer of that name. The sentence must be true for all of them, and any remedy it names must be a control the user can find where it points. When citing what a user read, quote the copy as of the incident date (`git show <commit-at-date>:<file>`): writing this up, I first quoted today's wording, and both users had seen older text.
**Rule:** An error sentence names only what every producer of its code proves; a remedy it names must exist at its destination.
**Enforcement update:** per-surface tests that pin "never says X for code Y" (each negative-controlled). No hook: "true for every producer" needs a reading, not a match.
