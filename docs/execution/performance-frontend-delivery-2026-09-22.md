## Deliberate boundaries

- No virtualization was added. The measured selection/inspector rerender fan-out is addressed by memoization, while virtualization would alter keyboard navigation, collapsed groups, browser find, assistive-technology exposure, and loaded-selection semantics. Browser scrolling/DOM-memory profiling at 50/250/1,000 rows is still needed to establish a remaining scrolling bottleneck before accepting those tradeoffs.
- No auth/security freshness, destructive preview freshness, background action polling, or server truth was relaxed. The five-minute chart cache affects revisits only and is invalidated by existing safety paths.
- Unknown action scope intentionally retains broad reconciliation. Mutation cache garbage collection naturally falls back to broad reads, preserving correctness after long-running or restored jobs.
- Optional badges becoming client-owned is a critical-path tradeoff, not a claim that total transferred requests always decrease. Existing Home/Triage cache sharing, full-page parallel prefetch, preconnect, and guarded mailbox resets remain.
