## Three content briefs

### Clean Email alternatives

Existing destination: `/alternatives/clean-email`. Buyer stage: consideration.
Intent: choose between native Gmail and a cleanup product. Review the current search
results and existing page before editing; search impressions alone do not prove a
content defect.

Useful contribution to test for: a compact decision guide tied to actual jobs,
followed by a real DeclutrMail scope-preview example and accurate one-time versus
recurring packaging. Cite each competitor's current primary sources. Preserve a fair
native-Gmail option and explain provider coverage. Do not rewrite competitors' pages.

Primary outcome: qualified Gmail connection and first cleanup from this entry path.
Supporting observations: relevant query impressions and clicks. Ship only if the
review finds a concrete missing answer or stale claim.

### Trimbox safety and cleanup scope

Existing destinations: `/alternatives/trimbox` and `/vs/trimbox`. Buyer stage:
consideration. Intent: understand permissions, processing boundaries, and recovery.

Useful contribution to test for: a sourced comparison of the exact data boundary,
Gmail permissions, current product scope, and recovery limits. Link to both vendors'
own privacy/security material with review dates. Distinguish access permission from
what an application fetches or stores. Do not imply a competitor is unsafe or that
DeclutrMail never reads any email metadata.

Primary outcome: a qualified connection after understanding the scope. Guardrails:
no unsupported security promises or expanded tracking.

### Stop promotional emails in Gmail

Existing destination: `/how-to/stop-promotional-emails-gmail`. Buyer stage:
problem-aware. Intent: distinguish unsubscribing, filtering, and clearing old mail.

Useful contribution to test for: native Gmail instructions first, a clear distinction
between future mail and existing backlog, and a labeled product example only where
it helps. Check [Google's current subscriptions guidance](https://support.google.com/mail/answer/15621070)
and actual product behavior. Archive does not free Gmail storage. Unsubscribe is
not an immediate guarantee and cannot be recalled through Activity Undo.

Primary outcome: a useful answer and qualified first cleanup. Supporting observation:
relevant discovery in ordinary and AI Search reports, kept separate from conversions.
