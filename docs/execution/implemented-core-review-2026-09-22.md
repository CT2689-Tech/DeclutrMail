## Preservation review

- No API endpoints, wire contracts, entitlement definitions, preview payloads, Gmail mutations, workers, auth or billing code changed in this workstream.
- Home projects data already read by Home. No additional API call; sender previews open `/senders?sender=…`.
- Senders search remains server-scoped; counts retain unknown/approximate handling. Stale rows remain inert. Bulk controls, protected exclusions, saved views, sort, historical Archive/Delete scopes and time windows remain intact.
- Sender detail keeps protection reason/control, recommendation distinction, all action choices, recent messages, Gmail link and decision timeline. Monthly values show only supplied received-volume data.
- Triage keyboard decisions, focus skip, batch preview and guided journeys remain unchanged. Initial preference loading does not run an action.
- Screener has no delivery gate. No incomplete-window search was added.
- Autopilot filters are view state, not rule mutations. Pause-all still applies to the full rule set. A tier-blocked Active rule is never counted as Acting.
- Activity window totals, outcomes, recovery/undo, stale-data guards, pagination and support export dialog remain intact; weekly query remains separately scoped by the existing sender query.
- All changes use the existing palette and component system. Browser checks, actual focus appearance and viewport screenshots are owned by the parent review; source/tests do not certify visual quality.
