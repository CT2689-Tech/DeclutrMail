# Interaction performance review — 2026-09-24

Scope: the missing sender archived count in production, sender selection/search/filtering, and a code review of the main interaction layers across the app. This is not a claim that every production route has been profiled or that every remaining opportunity should be implemented without measurement.

## Production count

The authenticated production inspector reproduced the report: Inbox showed a count and Archived showed `—`. Latest main (`69175e17`, PR #765) already implements `archivedCount` in `SendersReadService`, passes it through the controller and adapter, and renders it in both detail layouts. The existing integration tests cover Inbox, archived mail, and exclusion of Trash/Spam/Draft/Chat. The latest Cloud Run deployment was still waiting for CI while the new web interface was already accessible. The most recent successful preceding Cloud Run workflow deployed `35b9a914`, which predates this field. The deployment subsequently completed successfully and both reported senders displayed numeric archived counts in the authenticated browser after refresh. This confirms web/API release skew, not a reason to calculate archived as lifetime received minus Inbox: that would incorrectly include deleted and excluded messages.

Deployment: https://github.com/CT2689-Tech/DeclutrMail/actions/runs/35969940882
