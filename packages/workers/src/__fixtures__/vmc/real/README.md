# Real production VMC fixture (ADR-0034)

One genuine, unmodified VMC chain and the artwork it commits to, used
by `vmc-verifier.test.ts`.

| file                      | what it is                                            |
| ------------------------- | ----------------------------------------------------- |
| `bankofamerica.chain.pem` | Leaf + DigiCert VMC intermediate + DigiCert VMC root   |
| `bankofamerica.svg`       | The mark the leaf commits to (SVG Tiny PS, 1399 bytes) |

Fetched 2026-08-17 from the live BIMI record:

```
default._bimi.bankofamerica.com  IN TXT
  "v=BIMI1; l=https://vmc.digicert.com/f0350c6b-….svg;
             a=https://vmc.digicert.com/f0350c6b-….pem"
```

Both are public artifacts, published for exactly this purpose — every
BIMI-supporting mail client fetches them on the open internet.

## Why a real certificate and not a generated one

The sibling fixtures in `../` are generated by OpenSSL, and their
logotype extension carries the logo's **SHA-256**. That is not what
issuers do. Every VMC in production commits with **SHA-1**, so the
generated fixture encoded the verifier's own assumption rather than the
ecosystem's behaviour — the suite was fully green while `verifyVmc`
rejected 100% of real certificates and the whole feature was dead in
production (2026-08-17; see MISTAKES.md).

A synthetic fixture cannot catch that class of bug, because whoever
writes the fixture and whoever writes the check make the same
assumption. This one is the ecosystem's own bytes:

- the logotype commitment really is SHA-1,
- the chain really terminates at `DigiCert Verified Mark Root CA`,
  which is absent from Node's TLS root store,

so it exercises both halves of the fix in their real encoding.

## Expiry

The leaf is valid 2026-04-11 → 2027-04-13. The test pins `verifyVmc`'s
injectable clock to `2026-09-01`, so this fixture does NOT rot when the
certificate expires — the assertion is about encoding and chaining, not
about Bank of America's renewal schedule.

To refresh it (only needed if the record itself changes):

```bash
rec=$(dig +short TXT default._bimi.bankofamerica.com | tr -d '"\\')
curl -o bankofamerica.svg       "$(echo "$rec" | grep -oE 'l=[^;]+' | cut -c3-)"
curl -o bankofamerica.chain.pem "$(echo "$rec" | grep -oE 'a=[^;]+' | cut -c3-)"
```
